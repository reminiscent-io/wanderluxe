🎯 Goal

Your current itinerary layout (as seen in the PDF) is text-heavy and timeline-oriented, which looks great on desktop but becomes overwhelming on mobile ￼.
We’ll convert it into a swipeable, card-based mobile experience that’s both elegant and efficient.

⸻

📱 Mobile Redesign Recommendations

1. Card-Based Daily Layout

Each “Day” becomes a stackable swipe card:
	•	Minimal top summary (date, location, hero image).
	•	Expandable content sections: Activities, Hotels, Transport, Dining.
	•	Accordion or swipe-up modal for details.

Design trend inspiration: Google Trips + Notion mobile + Apple Journal.

// src/components/trip/timeline/DayCard.tsx
import React from "react";
import { ChevronDown } from "lucide-react";

export const DayCard = ({ day }) => (
  <div className="rounded-xl shadow-sm bg-white dark:bg-neutral-900 mb-4 overflow-hidden">
    <div className="p-4 flex justify-between items-center">
      <div>
        <h3 className="text-lg font-semibold">{day.title}</h3>
        <p className="text-sm text-gray-500">{day.dateFormatted}</p>
      </div>
      <ChevronDown className="text-gray-400" />
    </div>
    <div className="px-4 pb-4 space-y-2">
      {day.sections.map((section) => (
        <div key={section.title} className="border-l-2 pl-3 border-gray-200">
          <p className="font-medium text-gray-700">{section.title}</p>
          <p className="text-sm text-gray-500">{section.summary}</p>
        </div>
      ))}
    </div>
  </div>
);

🧠 Tip: Show only top 2 events per section on load, with a “Show all” expandable animation.

⸻

2. Floating Sticky Navigation

Use a floating “Day Navigator” at the bottom — horizontally scrollable:

<BottomNav>
  <ScrollSnap>
    Day 1 • Day 2 • Day 3 …
  </ScrollSnap>
</BottomNav>

	•	Similar to Instagram Stories navigation.
	•	Lets users jump between days quickly.
	•	Use Framer Motion for smooth microinteractions.

⸻

3. Smart Typography & Readability
	•	Use a responsive text scale (clamp(14px, 2vw, 18px)).
	•	Limit each paragraph to 5 lines max before “Expand”.
	•	Apply line-height: 1.6 for longer trip day descriptions.

p {
  display: -webkit-box;
  -webkit-line-clamp: 5;
  -webkit-box-orient: vertical;
  overflow: hidden;
}


⸻

4. Lazy Loading & Skeletons

Each day’s details load on scroll or tap, reducing mobile bandwidth.

Add a shimmer loading effect for first load:

<div className="animate-pulse h-24 bg-gray-200 rounded-lg"></div>


⸻

5. Visual Anchors (Mini Maps + Icons)

Add visual context:
	•	Inline Google Maps thumbnail for each location.
	•	Use consistent iconography for:
	•	✈️ Flight
	•	🏨 Hotel
	•	🍽 Dining
	•	🧭 Activity

This helps scanning while scrolling.

⸻

6. Offline & Share Mode

Add “Download Day” or “Save for Offline” via PWA caching.
Also, create a mobile-friendly share view (/trip/:id/public) using the same card layout.

⸻

At top of trip view:

<HeroSection>
  <Image src={unsplashHero} className="rounded-lg" />
  <h1 className="text-2xl font-bold mt-2">{trip.title}</h1>
  <p className="text-gray-500">{trip.dateRange}</p>
</HeroSection>

Make it edge-to-edge with a gradient overlay and parallax scroll for modern feel.
