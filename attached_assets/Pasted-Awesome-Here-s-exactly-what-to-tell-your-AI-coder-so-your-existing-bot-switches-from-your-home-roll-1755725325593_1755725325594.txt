# 2) Backend: new Edge Function skeleton

Create/replace a Supabase Edge Function `chat-assistant` that:

* Creates/gets a **thread** per chat.
* Uploads user files (or passes Supabase Storage signed URLs) to the Assistant.
* Streams run status, relays assistant messages to the frontend.
* Handles **tool calls** (Actions) by calling your API and sending the results back via `submit_tool_outputs`.

```ts
// supabase/functions/chat-assistant/index.ts
import OpenAI from "openai";
import { serve } from "https://deno.land/std/http/server.ts";

const openai = new OpenAI({ apiKey: Deno.env.get("OPENAI_API_KEY")! });

// routing rule: cheap for trivial, 4o for parsing/reasoning
const pickModel = (payload: { hasFile: boolean; task: "parse"|"light"|"research" }) =>
  payload.task === "light" && !payload.hasFile ? "gpt-4o-mini" : "gpt-4o";

serve(async (req) => {
  const { threadId, message, files, userId, task } = await req.json();

  // 1) ensure thread
  const thread = threadId
    ? { id: threadId }
    : await openai.beta.threads.create({});

  // 2) attach files (optional)
  let file_ids: string[] = [];
  for (const f of (files ?? [])) {
    // Option A: raw upload:
    // const uploaded = await openai.files.create({ file: f, purpose: "assistants" });
    // file_ids.push(uploaded.id);
    // Option B: if you store in Supabase, create a signed URL and send as content text with URL
  }

  // 3) add user message
  await openai.beta.threads.messages.create(thread.id, {
    role: "user",
    content: [{ type: "text", text: message }],
    attachments: file_ids.map(id => ({ file_id: id })),
  });

  // 4) run assistant
  const model = pickModel({ hasFile: (file_ids.length>0), task: task ?? "parse" });
  const run = await openai.beta.threads.runs.create(thread.id, {
    assistant_id: Deno.env.get("OPENAI_ASSISTANT_ID")!,
    model, // override if needed
    // instructions can be appended here if you want dynamic context, else keep in assistant
  });

  // 5) handle tool calls loop (blocking simple version)
  let runStatus = await openai.beta.threads.runs.retrieve(thread.id, run.id);
  while (runStatus.status === "requires_action") {
    const toolCalls = runStatus.required_action!.submit_tool_outputs.tool_calls;
    const outputs = await Promise.all(toolCalls.map(async (tc) => {
      switch (tc.function.name) {
        case "get_schema": {
          const args = JSON.parse(tc.function.arguments);
          const result = await fetch(`${Deno.env.get("API_URL")}/schema`, {
            method: "POST", headers: { "Content-Type": "application/json" },
            body: JSON.stringify(args)
          }).then(r => r.json());
          return { tool_call_id: tc.id, output: JSON.stringify(result) };
        }
        case "search_trips": {
          const args = JSON.parse(tc.function.arguments);
          const result = await fetch(`${Deno.env.get("API_URL")}/trips/search`, {
            method: "POST", headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ ...args, userId })
          }).then(r => r.json());
          return { tool_call_id: tc.id, output: JSON.stringify(result) };
        }
        case "create_event": {
          const args = JSON.parse(tc.function.arguments);
          const result = await fetch(`${Deno.env.get("API_URL")}/events/create`, {
            method: "POST", headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ ...args, userId })
          }).then(r => r.json());
          return { tool_call_id: tc.id, output: JSON.stringify(result) };
        }
        case "update_event": {
          const args = JSON.parse(tc.function.arguments);
          const result = await fetch(`${Deno.env.get("API_URL")}/events/update`, {
            method: "POST", headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ ...args, userId })
          }).then(r => r.json());
          return { tool_call_id: tc.id, output: JSON.stringify(result) };
        }
        default:
          return { tool_call_id: tc.id, output: JSON.stringify({ error: "Unknown tool" }) };
      }
    }));

    await openai.beta.threads.runs.submitToolOutputs(thread.id, run.id, {
      tool_outputs: outputs
    });
    runStatus = await openai.beta.threads.runs.retrieve(thread.id, run.id);
  }

  // 6) fetch latest messages to return to UI
  const messages = await openai.beta.threads.messages.list(thread.id, { order: "asc" });

  return new Response(JSON.stringify({ threadId: thread.id, messages }), {
    headers: { "Content-Type": "application/json" }
  });
});
```

**Notes**

* Keep Supabase **RLS ON**; the API behind Actions enforces auth/ownership with your JWT.
* Do **not** expose service role to the assistant; the Edge Function is your trusted proxy.

# 4) Register the Actions in your OpenAI Assistant

In the OpenAI UI (or via API), add these **functions** with JSON schemas:

* `get_schema(tables?: string[])`
* `search_trips(traveler_id: string, query?: string)`
* `create_event(trip_id: string, type: "accommodation"|"transportation"|"activity"|"reservation", fields: object)`
* `update_event(type: "...", event_id: string, patch: object)`

These **do not** display JSON in chat; they pass arguments silently.
